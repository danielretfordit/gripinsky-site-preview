# Популярность в каталоге

Источник: предоставленный заказчицей файл «Доход с курсов за год.xlsx», лист «Лист1», столбцы A–B. Период из заголовка C1: август 2025 – август 2026. Для пар берём первое число (явное решение заказчицы 07.10.2026). Выручка не участвует.

В сайт и публичный репозиторий записаны только порядковые места (`popularityRank`). Меньше = популярнее. Равное количество = одинаковое место; при равенстве сохраняется порядок каталога. Позиции без данных идут после сопоставленных. Исходная таблица, выручка и количества покупок не копируются в репозиторий.

## Исключения

- B6 («Пакет 2 + 3 + V-Ray») хранится как дата. Место не назначено.
- B39 («Анимация в 3DS MAX») также дата; отдельной активной позиции каталога нет.
- Строки 29, 40, 46, 52, 59: нет точно соответствующей активной позиции. Продажи не распределялись на похожие пакеты.
- Строка 57 «Нейросети»: требуется подтверждение связи с новым «ИИ в 3D». Данные не перенесены ни в основной курс, ни в лабораторию.
- Новая «База 3D-визуализатора»: исторические продажи сохранены за исходным пакетом уровней 1+2+3.
- Бесплатные курсы и услуги без записей: отсутствие данных, не нулевые продажи.

## Обновление

Использовать одинаковый период и одну метрику для всех позиций. После пересчёта обновить все места в админке и подпись периода в каталоге. Не вводить количество продаж в поле позиции. Новый отчёт не смешивать с текущим.
