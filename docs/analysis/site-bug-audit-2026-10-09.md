# Проверка сайта 9 октября 2026

Проверена локальная готовая сборка, 160 публичных страниц и страница 404 на ширинах 375, 768, 1024 и 1440 px. Проверки включали статус ответа, ошибки JavaScript, гидратацию, загрузку видимых изображений, горизонтальную прокрутку и выход элементов за границы. Отдельно проверены навигация, FAQ, галерея, формы, корзина и игровые профессии.

## Исправлено

- Переход по изображению карточки курса перекрывался другим слоем. Добавлена ссылка на всю карточку с сохранением самостоятельных действий.
- Старые ссылки на базу, пакет и подбор после замены визуализации вели к удалённым якорям. Обновлены ссылки и восстановлен переход к базе и выбранной профессии.
- Ссылки главной на отдельные отсутствующие отзывы заменены переходом к действующей вкладке отзывов.
- В навигации курса без FAQ показывалась ссылка на отсутствующий раздел.
- Меню закрывается по Escape, клику вне меню и выбору ссылки; по Escape фокус возвращается на переключатель.
- В геймдеве обработчики переходов к основным и дополнительным курсам и ResizeObserver создавались при каждом переключении профессии. Теперь создаются один раз, якоря следуют активной профессии.
- Слайдер главного экрана останавливается вне экрана.
- В готовой Node-сборке `/blog` возвращал 404 из-за конфликта файла страницы с папкой статей. Формат сборки изменён на directory, публичные адреса без завершающего слэша сохранены. Проверки маршрутов и SEO адаптированы к index.html.
- Исправлены два нарушения оформления текста на главной. Авторские отзывы не менялись.

## Результаты

- Сборка: успешно, 0 ошибок и предупреждений, 2 существующих подсказки типов.
- Модульные проверки расчётов: 20 из 20.
- Браузерный проход: 774 прошли сразу, 8 прошли повторную проверку, 18 пропущены по условиям сценариев. Итого 782 успешные проверки из 800 запланированных.
- Причины повторных запусков: смена сети Chromium и устаревшая проверка изображений в закрытых блоках. Проверка учитывает реальную видимость элемента.
- SEO: 160 страниц, 0 ошибок, 0 предупреждений.
- Оформление текста: 170 страниц сборки, 0 ошибок, 0 предупреждений; архивы дизайна, юридические тексты и перенесённые авторские статьи исключаются по правилам проекта.
- Все внутренние ссылки и якоря публичной сборки проверены: отсутствующих целей нет.

Команды браузерной проверки: `playwright test pages.spec.ts navigation.spec.ts gallery.spec.ts forms.spec.ts cart.spec.ts gamedev.spec.ts`, затем `playwright test --last-failed --workers=1 --retries=1`.

## Границы проверки

Оплата и отправка заявок проверялись с подменой ответов API, реальные платежи и заявки не отправлялись. Продакшен-хостинг, реальные CRM-интеграции и локальная административная панель Keystatic не входят в подтверждённые результаты. 19 маршрутов старой Tilda ещё не перенесены; скрипт проекта отмечает их отдельно.
