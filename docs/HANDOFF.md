Визуальные правила исходного брифа обновлены 08.10.2026. Для размеров кнопок и текущего оформления применять [систему оформления](design/system.md) и [роли текста](design/text-hierarchy.md); прежние визуальные значения ниже сохранены как история решений.

Передача проекта из Claude (Cowork) в Claude Code. Здесь собрано всё, что решили в диалоге: цель, бренд, структура страницы, тексты, цены, правила и открытые вопросы. Прототип страницы лежит рядом в папке `prototype/`.

## 1. Что это и зачем

- **Школа:** Академия 3D GRIPINSKY (Евгений Грипинский), онлайн-курсы по 3ds Max, Corona Renderer, визуализации интерьеров и экстерьеров. Сайт: gripinsky.ru.
- **Задача:** новый сайт. Начали со страницы направления «3D-визуализация». Главная тоже сделана в черновике (отдельный артефакт).
- **Главная проблема старого сайта:** база и профессия продаются отдельно, связки нет. Новая страница ведёт человека по пути: **Шаг 1 база → Шаг 2 профессия → пакет**.
- **Что продаём:** не сертификат, а навыки и портфолио. Лицензии на образование нет, поэтому сертификат честно называем «просто бумагой», а налоговый вычет не упоминаем.

## 2. Что лежит в папке

```
gripinsky-3d-viz/
  HANDOFF.md            этот файл
  CLAUDE.md             короткие правила для Claude Code
  prototype/            рабочий интерактивный прототип (открыть index.html в браузере)
    index.html          страница направления
    gallery.html        галерея работ
    dc-runtime.js       рантайм прототипа (React-подобный шаблонизатор, только для показа)
    images/             все картинки (49 шт., имена = id ассетов)
  source/               исходники в формате Design-артефакта (.dc.html)
  snapshot/             статичный HTML после рендера, без скриптов: удобно копировать вёрстку и тексты
```

Онлайн-версия (Design-артефакт, приватная): https://claude.ai/artifact/Btc2ufuGSBUr4fE5DCWrea
Главная (черновик): https://claude.ai/artifact/BcrNhnBro6TZENZj5ebSHg

> `dc-runtime.js` и формат `.dc.html` нужны только чтобы прототип работал. Для боевого сайта переписать на нормальный стек (см. раздел 10). Логика страницы (цены, пакет, тест, вкладки) лежит в `<script type="text/x-dc">` внизу `prototype/index.html`: класс `Component`, метод `renderVals()`.

## 4. Принципы, которые заказчица сформулировала

1. Суть схватывается глазами сразу. Меньше «табличек»: должно смотреться как сайт, а не таблица, в которой надо разбираться.
2. Описание курса визуально весит больше, чем тарифы.
3. Единая визуальная система: шаги 1 и 2 оформлены одинаково.
4. Реальные работы учеников, без повторов картинок.
5. Реальные отзывы.
6. **Без «ИИ-шных» знаков в текстах**: никаких длинных тире с пробелами (« — »), точек-разделителей «·» и стрелок «→» в тексте. Пишем обычными фразами. Стрелки допустимы только в ссылках («Смотреть →»). Цитаты учеников не трогаем.
7. Обычная прокрутка. Привязку прокрутки к экранам (scroll-snap) пробовали и убрали: «прокручивается кусками».
8. Перегруз снимаем визуально, а не сокращением текста.
9. Без жёлтых обводок блоков («колхоз») и без общих подложек: блоки разделяются воздухом и отдельными карточками.

## 10. Что делать дальше в Claude Code

1. **Выбрать стек.** Нужен статический сайт с компонентами, например Astro или Next.js (static export) + Tailwind с токенами бренда. Формы отправлять в Bitrix24 или GetCourse (что используется у школы — уточнить).
2. **Перенести страницу.** Брать из `snapshot/index_static.html` (вёрстка и тексты) и логику из `<script type="text/x-dc">` в `prototype/index.html`:
   - конструктор пакета;
   - тест из 4 вопросов;
   - вкладки результатов;
   - слайдер до/после;
   - FAQ.
3. **Вынести данные в файлы:** цены, профессии, курсы, работы, истории, награды (JSON/MDX). Работы и награды будут пополняться: каждый новый «Царь горы» добавляется одной записью.
4. **Мобильная версия:** её нет совсем, сделать адаптив.
5. **Картинки:** перевести в WebP/AVIF, сделать несколько размеров, `loading="lazy"`.
6. **Шаблоны:** главная, каталог курсов, страница курса, галерея, статьи.
7. **SEO и аналитика:** мета-теги, Open Graph, микроразметка Course/Review, Яндекс Метрика.
8. **Идеи, которые обсуждали, но не сделали:**
   - блок про деньги и окупаемость (цитата: «продал виз за 15 тысяч, потом дом, заработал 115 тысяч»);
   - полноценный блок автора;

   - работы «С наставником» показывать рядом с тарифом «Наставничество».
