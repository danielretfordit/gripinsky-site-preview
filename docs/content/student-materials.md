# Материалы учеников

Импорт от 08.10.2026: 937 изображений работ, 59 текстов отзывов, 8 видео. Убраны 180 точных повторов изображений. Дополнительные серматы сохранены рядом с проектами. Один файл с расширением PNG оказался PSD; он конвертирован, как и отдельная модель в TIFF.

На сайте показываются только выбранные точные цитаты об академии, преподавателях и обучении. Полные отзывы остаются в контенте как источник для редактора и не выводятся в пользовательском интерфейсе. 42 текста содержат выбранную цитату; тексты только о техническом процессе остаются в архиве.

Рабочие страницы: `/gallery`, `/otzyvy`. Три композиции на реальных материалах: `/design/student-results` (галерея, работа с цитатой, сермат с рендером). Рекомендуемая композиция: работа с цитатой.

Новые авторы имеют статус согласия `pending`; существующие статусы сохранены. В пилоте настройка `requireConsent` выключена. Имена взяты из папок авторов и файлов; служебные пометки соцсетей удалены. Категории определены по названиям папок и явным указаниям в отзыве; технические сцены без указания направления требуют редакторской проверки. PDF-презентации из папки наставников не выведены на сайт: их изображения и тексты уже представлены отдельными материалами, а сами PDF могут содержать контакты.

Источники и контроль импорта: `student-import-manifest.json`, `student-import-report.json`. Список выбранных цитат: `school-quotes.json`. Повторный импорт: `node scripts/import-student-assets.mjs`, затем `python3 scripts/import-student-reviews.py`, `node scripts/import-student-extras.mjs`, `python3 scripts/select-school-quotes.py`. Два восстановленных формата конвертированы отдельно. При повторном полном импорте сохранить эти записи.
