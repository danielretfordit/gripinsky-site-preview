# Проект: новый сайт Академии 3D GRIPINSKY

Полный контекст, решения и открытые вопросы: **HANDOFF.md**. Прочитай его первым.

## Коротко
- Общение с заказчицей на русском, коротко и по делу.
- Прототип страницы «3D-визуализация»: `prototype/index.html` (открыть в браузере), галерея: `prototype/gallery.html`.
- Чистая вёрстка без скриптов: `snapshot/`. Логика (цены, пакет, тест): `<script type="text/x-dc">` в `prototype/index.html`.
- `dc-runtime.js` и `.dc.html` только для показа прототипа, в боевой сайт их не переносить.

## Бренд
- Фон `#0D2023`, акцент лайм `#F8F61A` только для акцентов (не фон), Sea `#92BABE`.
- Шрифты Inter Tight + Caveat. H2 жирные, капсом.
- Без жёлтых обводок блоков и общих подложек. Блоки разделяются воздухом.

## Тексты
- Без « — », «·» и «→» в тексте (выглядит как ИИ). Стрелки только в ссылках.
- Продаём навыки и портфолио, не сертификат. Налоговый вычет не упоминать (лицензии нет).

## Нельзя
- Публиковать контакты учеников со скриншотов.
- Действовать в Instagram школы.
- Фейковые таймеры скидок.
