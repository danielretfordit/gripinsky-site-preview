# Гайдлайн сайта GRIPINSKY: стиль 04 «Студийный свет»

Единый источник правил оформления и вёрстки (с 09.10.2026). Основа: вариант 03 «Собранный ритм» плюс макет заказчицы с блоком основателя (полоса работ, лаймовая черта, цитата, цифры, боковая колонка). `system.md` и `text-hierarchy.md` остаются приложениями с замерами; при расхождении действует этот файл.

Живая витрина: `/styleguide` (закрыта от индексации, в sitemap не входит). Токены: `src/styles/global.css`. Проверки: `npm run lint:css`, `node scripts/audit-rhythm.mjs`, `npm run visual:audit`.

## 1. Принципы

1. Работа ученика главная. Настоящие рендеры вместо условных знаков и декоративных букв.
2. Графит, свет и один сигнал. Тёмный фон, светлые заголовки, мягкое студийное пятно света на панелях, лайм как подпись бренда.
3. Воздух. Между надзаголовком, заголовком, текстом и действием всегда есть промежуток из шкалы ритма. Слипшийся текст считается дефектом.
4. Крупно и плотно. Заголовки капсом, вес 800, крупная шкала; текст спокойный и читаемый.
5. Одинаково везде. Один примитив на одну задачу: надзаголовок, цитата, цифры, кнопка, рамка картинки.

## 2. Цвет

| Токен | Значение | Где |
|---|---|---|
| `--color-bg` | `#111313` | фон страницы |
| `--color-surface` | `#191D1D` | панели (блок доверия, ИИ, корзина) |
| `--color-ink` | `#F1F1EB` | заголовки, основной текст |
| `--color-ink-2` | `#C1C7C0` | абзацы |
| `--color-muted` | `#A1AAA3` | подписи |
| `--color-heading-muted` | `#A9AEAB` | вторая строка заголовка (`.t-accent`): ровный серебристый цвет, **без градиента в тексте** |
| `--color-lime` | `#E7E845` | сигнал |
| `--color-line` / `--color-line-strong` | светлый 18% / 42% | линии и черты |

**Лайм, где можно:**
- основная кнопка экрана (`.btn-primary`);
- черта 32×2 px перед надзаголовком секции;
- черта главной цитаты блока (`.quote--signal`); слова внутри цитаты лаймом не выделяются (решение 10.10.2026);
- рамка `.btn-signal` в блоке без жёлтой кнопки;
- знак «+» у цифр (`.num-plus`);
- активная вкладка, шаг, прогресс, фокус;
- лаймовые поля: блок курса «ИИ» на главной и финальная полоса «Поможем выбрать» (текст и кнопка на них тёмные). Больше двух лаймовых полей на странице не ставить.

**Лайм, где нельзя:** заголовки, сами цифры, ссылки, галочки, подложки карточек.

**Свет:** `--glow-studio` (нейтральное пятно) на панелях и за портретом, `--glow-signal` только в лаймовых зонах. Градиенты в тексте не используются.

## 3. Шрифты и роли текста

- Inter: заголовки, текст, кнопки, **надзаголовки и подписи** (капсом, разрядка `--tracking-label` 0.2em, роль `--type-label` 11–12 px, вес 600).
- JetBrains Mono: только «метаданные рендера» с цифрами и путями: счётчики `01 / 17`, номера `01`, `КУРС / 66 УРОКОВ` (`.t-meta`).
- Роли: `.t-hero` (H1 первого экрана, 34–72 px), `.t-display` (H1 внутренних, 36–84 px), `.t-h2` (34–68 px), всё капсом, вес 800, интерлиньяж 0.95–0.98. `.t-h3` и `.t-title` в обычном регистре. `.t-lead`, `.t-body`, `.t-small`, `.t-overline`, `.t-meta`, `.t-num`, `.t-quote`.
- Вторая строка заголовка: `<span class="t-accent">`. Длинный заголовок направления в две колонки: `.t-hero--long`.
- Локальных `font-size` в px нет (проверяет `lint:css`).

## 4. Ритм и сетка

| Связка | Токен | Значение |
|---|---|---|
| надзаголовок → заголовок | `--stack-eyebrow` | 14–20 px |
| заголовок → текст | `--stack-lead` | 16–24 px |
| H3 → текст | `--stack-tight` | 10 px |
| текст → действие | `--stack-action` | 24–36 px |
| между секциями | `--space-section` | 56–84 px |
| внутри секции | `--space-sub` | 40–56 px |
| заголовок секции → содержимое | `--space-head` | 20–32 px |

- Связки работают автоматически (правила в `global.css`). Компонент может задать своё значение, но не ноль.
- `scripts/audit-rhythm.mjs` ловит и слипшееся (меньше 12 px после заголовка), и пустоты (больше 160 px между блоками, больше 56 px внутри карточки). Исключение: выравнивание цен по нижнему краю в ряду карточек курсов.
- Крупные заголовки капсом: трекинг −0.038…−0.04em и `word-spacing: .14em`, иначе слова слипаются.
- Контейнер 1360 px, поле 20–24 px и safe-area (`.wrap`, `--gutter`, `--site-gutter`).
- Точки перелома: 560, 768, 1024, 1280. Между ними всё тянется через `clamp()`; блоки в колонках разной ширины перестраиваются через container queries.
- Цели нажатия не меньше 44 px, поля ввода от 16 px.

## 5. Примитивы (разметка)

```html
<!-- Надзаголовок секции: черта появляется сама, если сразу за ним заголовок -->
<p class="t-overline">Основатель академии</p>
<h2 class="t-h2">Евгений <span class="t-accent">Грипинский</span></h2>

<!-- Цитата. Главная цитата блока: .quote--signal, одно слово можно выделить -->
<blockquote class="quote quote--signal"><p>«…научить вас думать…»</p></blockquote>
<!-- Любой <blockquote> получает серую черту слева без классов -->

<!-- Цифры и факты: значение крупно, подпись с разрядкой, колонки через линии -->
<dl class="facts"><div><dt>выпускников</dt><dd>10 000<span class="num-plus">+</span></dd></div></dl>

<!-- Кнопки -->
<a class="btn btn-primary">Выбрать курс <span aria-hidden="true">↗</span></a>
<a class="btn btn-secondary">Подобрать курс <span class="arrow-long" aria-hidden="true"></span></a>
<a class="btn btn-signal">Все педагоги <span class="arrow-long" aria-hidden="true"></span></a>

<!-- Боковая колонка со словами-ориентирами (только от 1280 px, декоративная) -->
<div class="rail" aria-hidden="true"><p>3D<br>люди<br>знания</p><p><strong>GRIPINSKY</strong></p></div>
```

- Кнопки: одна жёлтая на экран, высота 48 px, радиус 2 px. Контурная с длинной стрелкой для второго действия. `.btn-signal` (56 px, лаймовая рамка) только в блоке, где нет жёлтой кнопки.
- Стрелки: `↗` в жёлтой кнопке и переходах наружу, длинная `.arrow-long` в контурных кнопках, `→` в текстовых ссылках «Смотреть →».
- Картинки: рамка `.media-frame` и пропорции `--media-ratio-*` (карточка 16:10, работа 4:3, портрет 4:5), радиус 2 px. При наведении кадр медленно приближается (только мышь, без reduced-motion).
- Портрет без рамки растворяется в фоне маской (блок основателя).
- Цитаты учеников не редактируются.

## 6. Компоненты страниц

- Шапка `Header.astro`: стекло (blur). На компьютере (шапка шире 960 px) все пункты меню в строке, бургера нет; от 1024 до 1200 px меню компактнее. На планшете и телефоне бургер открывает полноэкранное меню: крупные пункты с длинными стрелками, жёлтая кнопка консультации и Telegram.
- Первый экран `HeroWork`: на главной кинематографичный вариант `.hero--cinema` (работа ученика на весь экран, заголовок поверх затемнённой левой части, подпись и стрелки справа внизу); на направлениях две колонки, кадр выровнен по полям. Счётчик, стрелки 44 px, автосмена, свайп.
- Кнопка «наверх» `ToTop`: круг 52 px справа внизу, появляется после первого экрана, поднимается над корзиной и cookie.
- Цифры под первым экраном `StatsRibbon`: как `.facts`.
- Блок доверия `TrustBlock`: «Почему GRIPINSKY» (заголовок закреплён при прокрутке) → основатель (`FounderFeature`: цитата с лаймовой чертой, цифры, кнопка, портрет без рамки) → отзывы.
- Курс «ИИ»: лаймовое поле, настоящая сцена «сетка от ИИ / рендер художника».
- Финал каждой страницы `ConsultSection`: лаймовая полоса, тёмная кнопка, форма в тёмной карточке.
- Блог и новости: `PostCard` (обложка 16:10; без обложки знак академии на сетке).
- Баннеры и объявления: `AnnouncementBar`, `PromoBanner`, тон «Спокойный» или «Сигнал».

## 7. Устройства и браузеры

Safari и iOS 16.4+, Chrome 111+, Firefox 128+, Samsung Internet 22+, встроенные браузеры Telegram и VK (класс `is-inapp`, корзина в ссылке, запасной путь оплаты). Проверка: 375, 768, 1024, 1440 и матрица `docs/qa-devices.md`.

## 8. Тексты

Без « — », «·» и «→» в тексте (стрелки только в ссылках). Не писать «диплом», «квалификация», «налоговый вычет», «гарантия трудоустройства». Без таймеров. Зачёркнутая цена только реальная. Работы и истории только с согласием.

## 9. Чек-лист новой страницы

1. Один H1, роли текста из шкалы, вторая строка `.t-accent`.
2. Надзаголовок перед каждым H2 секции.
3. Ни одного нулевого промежутка: `node scripts/audit-rhythm.mjs` выдаёт 0.
4. Лайм только из списка в разделе 2.
5. Картинки через `astro:assets` и `.media-frame`.
6. `npm run lint:css`, `npm run visual:audit` без замечаний на 8 ширинах.
7. Финальный блок `ConsultSection` подключён через `Base.astro`.
