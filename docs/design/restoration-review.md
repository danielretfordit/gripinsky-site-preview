# Восстановление страниц, 06.10.2026

## Основание
Запрос заказчицы: вернуть подробную концепцию и путь ученика, потерянные при смене стиля. Источники: локальные HTML «2. 8.html», «Курс «ИИ в 3D» (1).html», HANDOFF и приложенные снимки метрик и форматов. Сохранён выбранный стиль «Графит и сигнал».

## Изменения
- Направление: пять метрик из настроек, отдельная четырёхступенчатая лесенка, результаты по направлениям, переходы к базе, профессии, работам и тесту.
- На компьютере ступени поднимаются равномерно; на телефоне выстраиваются вертикально.
- Курс ИИ: последовательность шести этапов, результат и инструменты каждого этапа, итоговый проект.
- При переходах к разделам устранено суммирование внутреннего отступа секции с отступом прокрутки.
- Быстрые клавиатурные переключения радио теперь исходят из фокуса текущей кнопки, фокус переносится без дополнительного скролла.
- В админке проверены настройки, курсы, работы и запись «SEO страниц». Для /ai метаданные соответствуют восстановленной программе.

## Проверка
- npm test: 12 из 12.
- Проверки страниц, тарифов, навигации и админки: 49 прошли, 3 пропущены намеренно (повтор админки на недесктопных размерах).
- После коррекции якорей: 48 из 48 сценариев навигации, тарифов и восстановленных блоков без повторов.
- Ширины: 375, 768, 1024, 1440. Снимки: docs/design/shots/restoration.
- Дизайнер и маркетолог завершили ревью. Агент тестировщика остановился по лимиту; браузерные и автоматические проверки завершены основным агентом.
- Проверка SEO: 156 страниц, ошибок нет. Проверка текстов: ошибок нет; архивные Title сохранены по правилу миграции.
- Карта адресов: 70 реализованы в пилоте, 20 пока ведут на старый сайт.

## Осталось для наполнения
В исходном HTML этапы ИИ содержали заглушки кадров. Нужны реальные кадры уроков для демонстрации каждого этапа. Новые изображения не выдавались за результаты учеников.
Это локальный пилот; публикация, боевые платежи и переключение домена в этот этап не входят.
