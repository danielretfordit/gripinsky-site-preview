# Обложки каталога

## Предлагаемая система

Обложка 16:10, основной исходник 1600×1000. На экране не более двух названий программ плюс количество остальных. Слева сверху уровень, справа метка новинки. Название и цена остаются живым текстом под изображением.

Вариант A «Результат»: крупный реальный итоговый проект. Рекомендуемый основной стиль каталога.
Вариант B «Процесс»: модель и рендер одной сцены. Использовать для курсов, где сравнение объясняет предмет обучения; не делать всю сетку одинаковыми половинками.

Визуальные пробы: `/design/course-covers/results` и `/design/course-covers/process`. В них использованы работы из локального архива для обсуждения композиции. Это не утверждение, что именно эти работы входят в каждый показанный курс. Перед заменой обложки проверить связь с курсом и разрешение автора.

Для базы: 2–3 реальных результата в одной композиции. Остальные готовые пакеты сняты с продажи по решению 07.10.2026; новые обложки для них не нужны. Для услуг: фотография/кадр разбора работы и понятная подпись. Чужие работы и сгенерированные изображения не выдавать за работы учеников. Пока в каталоге сохранены исходные картинки.

## Данные каталога

Новизна: метка и фактическая дата выхода в админке. Для «ИИ в 3D» метка задана по брифу; даты переноса не выдаются за запуск. Популярность: порядковое место по числу покупок за август 2025 – август 2026, первое число в паре по решению заказчицы 07.10.2026. В публичных JSON только место, без выручки и количества продаж. Полное сопоставление: `docs/analysis/catalog-popularity.md`.
