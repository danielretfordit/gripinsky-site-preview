# Админка сайта (Keystatic)

Адрес: `https://gripinsky.ru/keystatic`. Сначала браузер спросит пароль сервера (выдаёт администратор), затем Keystatic попросит войти через GitHub. Локально админка открывается по адресу `http://localhost:4321/keystatic` после `npm run dev`.

## Как устроено

- Каждое сохранение в админке становится коммитом в репозиторий `gripinskya-bit/gripinsky-site`.
- После коммита GitHub Actions проверяет сайт, собирает его и выкладывает на сервер (`.github/workflows/deploy-vps.yml`). Обычно это занимает 5–8 минут.
- Если проверка не прошла (например, акционная цена выше каталожной или пустое обязательное поле), сайт не меняется: на сервере остаётся прошлая версия. Ошибку видно во вкладке Actions репозитория.
- Каждую ночь в 00:05 по Москве сайт пересобирается сам: баннеры, акции и слайды включаются и выключаются по своим датам. Истёкший баннер пропадает у посетителей и без пересборки.

## Разделы

| Раздел | Что меняется |
|---|---|
| Витрина → Главная страница | заголовок и кнопки первого экрана, подписи к цифрам, карточки направлений, вопросы и отзывы на главной, блоки «ИИ в 3D» и «Сообщество» |
| Витрина → Слайды первого экрана | работы учеников в слайдере главной и направлений: порядок, подпись, кадр на телефоне, даты |
| Витрина → Баннеры и объявления | полоса над шапкой, баннер под первым экраном главной, сверху каталога и на странице курса; даты, страницы, тон |
| Витрина → Акции | акционные цены курсов на срок. Настоящая цена зачёркивается автоматически, на сайте пишется «до …» |
| Продажи | курсы, форматы обучения, профессии визуализации и игр |
| Доказательства | работы, награды, истории, отзывы, люди (с согласием на публикацию) |
| Тексты | вопросы, блог (статьи, новости, анонсы), документы, баннер cookie |
| Сайт | меню и подвал, настройки (контакты, цифры, рассрочка, скидки за набор), интеграции, стиль сайта |
| SEO страниц | title, description и закрытие от индексации отдельных адресов |

## Правила, которые проверяет сборка

- Тексты без « — », «·» и «→» (кроме ссылок вида «Смотреть →»). Не писать «диплом», «квалификация», «налоговый вычет», «гарантия трудоустройства». Без таймеров скидок.
- Акционная цена ниже цены курса в каталоге, у акции есть дата окончания.
- Люди и работы показываются только при согласии на публикацию.
- Картинки работ: JPG или WebP до 3 МБ, длинная сторона 1600–2400 px.

## Подключение онлайн-админки (один раз, администратор)

1. В GitHub создать GitHub App по инструкции Keystatic (`https://keystatic.com/docs/github-mode`): доступ только к репозиторию `gripinsky-site`, права Contents: read and write, Metadata: read. Адрес возврата: `https://gripinsky.ru/api/keystatic/github/oauth/callback`.
2. На сервере в `/etc/gripinsky/env` добавить: `KEYSTATIC_STORAGE=github`, `KEYSTATIC_GITHUB_CLIENT_ID`, `KEYSTATIC_GITHUB_CLIENT_SECRET`, `KEYSTATIC_SECRET` (случайная строка 32+ символа), `PUBLIC_KEYSTATIC_GITHUB_APP_SLUG`.
3. В репозитории: переменная `PUBLIC_KEYSTATIC_GITHUB_APP_SLUG`, переменная `VPS_ENABLED=true`, секреты `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY`, `VPS_KNOWN_HOSTS`.
4. Пригласить заказчицу в репозиторий с правом записи.
5. Пароль nginx на админку: `htpasswd -c /etc/nginx/gripinsky-admin.htpasswd editor`.

Если GitHub из России недоступен или работает с перебоями, правки можно вносить локально (`npm run dev`, затем коммит), а на сервере включить таймер, который сам забирает изменения из репозитория (см. `deploy/README.md`).

## Откат правки

Во вкладке Commits репозитория найти коммит из админки и нажать Revert, либо откатить сервер на прошлый релиз (`deploy/README.md`, раздел «Выкладка версии»).
